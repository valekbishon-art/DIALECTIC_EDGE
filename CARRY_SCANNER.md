# Funding Carry Scanner — как пользоваться

## Что это и почему именно это

Мы прогнали бота через 7+ строгих бэктестов (2020-2026). **Прогноз направления цены
edge не несёт** — рынок на дневках эффективен, а follow-сигналы бота вообще
анти-предиктивны. Единственное, что пережило все проверки — **дельта-нейтральный
funding carry**: не угадывание цены, а сбор структурной премии фандинга.

**Бэктест carry (динамический выход, порог ≥20-30% годовых, реалистичные косты):**
+30%+ годовых, робастно в КАЖДЫЙ торгующий год, переживает косты. Природа —
«заряженное ружьё на эйфорию»: жнёт жирно в манию, спит в штиле.

Поэтому бот — **не предсказатель, а сканер**: показывает, ГДЕ сейчас открыта
carry-возможность. Решение и исполнение — руками.

## Запуск

```bash
python scripts/funding_scanner.py                  # 15 ликвидных активов (рекомендуется)
python scripts/funding_scanner.py --threshold 30   # свой порог годовых (деф 20)
python scripts/funding_scanner.py --capital 5000   # + расчёт размера позиции под $5000
python scripts/funding_scanner.py --watch 600      # авто-обновление каждые 600 сек
python scripts/funding_scanner.py --watch 600 --telegram   # + пинг в Telegram при возможности
python scripts/funding_scanner.py --all            # ВСЕ перпы (опасно, см. ниже)
```

Источник — Binance fapi (live, без ключей). Если геоблок (451) — включи VPN.

**Боевой режим** (фон, пинг на телефон): `python scripts/funding_scanner.py --watch 600 --telegram --capital 5000`
— проверяет рынок каждые 10 мин и шлёт в Telegram, когда фандинг разгонится. Дедуп: по
каждому символу алерт шлётся один раз (повторно — только если ушёл из списка и вернулся).

## Telegram-алерты (настройка)

Бот берёт `BOT_TOKEN` и чаты из env (тот же токен, что у основного бота):
```
BOT_TOKEN=123456:ABC...                 # токен от @BotFather
CARRY_ALERT_CHAT_IDS=123456789          # твой chat_id (или ALERT_ENGINE_CHAT_IDS)
```
Узнать chat_id: напиши боту, открой `https://api.telegram.org/bot<TOKEN>/getUpdates`.
Без этих переменных `--telegram` просто молча пропустит отправку (печатает в консоль).

## Размер позиции (`--capital N`)

Дельта-нейтраль = равный объём на ногу. Под депозит C: спот-нога = перп-нога = C/2
(вторая половина — маржа под шорт-перп 1x). Бот печатает раскладку и ожидаемый
доход/день·мес·год (гросс, до костов).

## Как читать вывод

| статус | годовых | что значит |
|---|---|---|
| 🟢🟢 PRIME | ≥30% | прайм-возможность, бэктест-зона максимума |
| 🟢 CARRY | ≥20% | рабочая возможность |
| ⚪ тонко | 8-20% | фандинг есть, но косты съедят большую часть |
| · спим | 0-8% | торговать нечего |
| 🔴 отриц | <0 | шорты платят лонгам (обратный carry) |
| 🔵 REVERSE | ≤−20% | отрицательный экстрим (обратная игра) |

Строки с `▶` — превысили порог, бот разберёт их отдельно с готовой «игрой».

## Что делать, когда бот нашёл возможность (🟢)

Положительный жирный фандинг = лонги перегреты, платят шортам. Игра:

1. **ЛОНГ спот** актива (купить на спот-рынке) — например `BTC` на спот.
2. **ШОРТ перп** того же актива (`BTCUSDT` perpetual), **равный объём** в деньгах.
3. Цена захеджирована (ноги гасят друг друга) → ты собираешь фандинг каждые 8ч.
4. **ВЫХОД:** когда годовой фандинг нормализуется (<8%) или перевернётся в минус —
   закрыть обе ноги. Не держать тупо по таймеру (в медведе фандинг уходит в минус
   и ты начинаешь ПЛАТИТЬ — это убивало фикс-холд в бэктесте).

## Честные риски (грааля нет, edge есть)

- **Сейчас (2026) фандинг низкий** — на ликвидных мажорах возможностей нет. Это
  норма. Не насилуй рынок — жди разгона (фандинг растёт в эйфории/мании).
- `--all` находит фандинг 100-500% на экзотике (мемы, токен-акции). Там фандинг
  реальный, но **ликвидность тонкая, спот не достать, риск ликвидации зверский** —
  carry тебя съест на исполнении. Только для опытных и малым объёмом.
- Бэктест = **верхняя оценка**. Реал съест: спред двух ног, маржа под шорт,
  риск ликвидации при резком движении, капы биржи. Чистыми будет меньше.
- Это **не пассивный доход 24/7**, а условная стратегия. Большую часть времени
  спит. Зарабатывает эпизодами — в периоды жирного фандинга.

## Что НЕ делать

Не торговать follow-сигналы старого бота (trend/L-S/funding-follow) — бэктест
показал, что они **робастно убыточны** (бот по ним торгует задом наперёд).
Подробности — в `bt_*.json` и memory.
